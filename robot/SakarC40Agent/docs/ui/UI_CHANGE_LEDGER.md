# UI Change Ledger

Every UI change (new screen, new route, new component, or modification to an existing one) gets a
row here. This is what lets a future session recognize "this was already tried/built" instead of
silently recreating it.

**This ledger is seeded starting 2026-09-25**, from the changes made earlier in the same working
session that produced this governance pass. It is not a retroactive reconstruction of the
project's entire prior history - earlier work is described where it's directly relevant (e.g. as
"pre-existing" in the rows below), but was not individually dated.

## How to add a row

Before merging a UI change:
1. Run `ui_preflight` (feature name, screen name, desired behavior).
2. Fill in every column above - especially `duplicate_check` (what you searched, what you found)
   and `validation_result` (what you actually verified on-device, not what you expect to work).
3. If you touched `FEATURE_REGISTRY.json`, `ROUTE_REGISTRY.md`, or `COMPONENT_REGISTRY.md`, say so
   in `files_changed`.
